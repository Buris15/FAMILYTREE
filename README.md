# Lacsamana–Ortega Family Archive v14

Deployment guide: [README-DEPLOY.md](README-DEPLOY.md).

Important: the shared family tree row is public-readable when published. Review and remove private details about living relatives before deployment. Never commit `.env.local` or place a Supabase secret key in Vercel.

Run `npm run check` for static validation. Run `npm run dev` after installing and logging into the Vercel CLI.


V15 adds invited family-contributor accounts, moderated submissions, private contribution attachments, a digital family museum, evidence-aware migration stories, and migration/museum sections in the printable family legacy book. See README-DEPLOY.md and run supabase/migrations/002_family_contributions.sql in an existing V14 Supabase project.
